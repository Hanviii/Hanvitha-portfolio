# Hanvitha Koney — Modern Portfolio

A clean, modern, responsive multi-page portfolio based on the current resume.

## Pages
- Home
- About
- Skills
- Projects
- Achievements
- Contact
- Resume overview

## Included resume
`Hanvitha_Koney_Resume.pdf` is the original uploaded resume. Every Download Resume button points to this PDF.

## Technologies
HTML5, CSS3, JavaScript, jQuery, Google Fonts.

## Run
Open `index.html` or use VS Code Live Server.

## Deploy on GitHub Pages
1. Create a repository.
2. Upload the complete folder.
3. Settings → Pages.
4. Deploy from `main` / `/root`.
5. Open the generated public URL.

## Deploy on Netlify
Upload the complete folder or connect the GitHub repository.

## Assignment compatibility
The project is a multi-page website and demonstrates HTML structure, CSS presentation, JavaScript interaction, jQuery, responsive design and cloud-ready static hosting.
